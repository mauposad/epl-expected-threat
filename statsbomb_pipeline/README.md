# StatsBomb Data Pipeline

This is a folder where we are currently deriving metrics from the StatsBomb Open Data Repository. 
From this we will derive metrics such as:

    - xThreat (Completed)
    - PPDA
    - OBV
    - Shot quality metrics (On Ball Value)
    - Field Tilt
    - Pressing Zones + Heat Maps
    - Team Style Metrics
    - Defensive Interruption
    - Goalkeeper Claim / Action Profile

From these important metrics we can then build meaningful models for our winning formula
