# data-mine-mposadas
Project for Data Mining



### Current ideas for projects
1. *Wildfire Risk & Prediction System (Colorado / Global Extension)*
    - **Problem**: Wildfires are worsening due to climate change. Agencies need predictive models for prevention & resource allocation.

    - **What you’d do**:
Mine historical fire perimeters, weather, vegetation, topography.

        - Engineer features (humidity, wind, drought index, land cover).

        - Train a model (e.g., XGBoost, Random Forests, or Deep Learning) to predict fire ignition probability or growth potential.

        - Build an interactive dashboard (FastAPI + Plotly Dash/Folium) to visualize fire risk in Western Colorado.

    - **Impact**: Direct link to disaster response and climate resilience → makes a killer resume bullet.

2. *Smart City Energy Demand Forecasting*

    - **Problem**: Power companies must anticipate spikes (heat waves, winter storms).

    - **What you’d do**:
Gather hourly energy usage data (many utilities publish anonymized sets).

        - Combine with temperature, seasonality, events (holidays).

        - Train time series models (LSTMs, Prophet, ARIMA).

        - Deploy as a dashboard for load forecasting.

    - **Impact**: Connects to sustainability and grid resilience → hot career area.

3. *Fraud / Anomaly Detection in Financial Transactions*

    - **Problem**: Fraud detection is a classic high-impact domain.

    - **What you’d do**:
Use open datasets like credit card fraud detection (Kaggle).

        - Experiment with unsupervised anomaly detection (Isolation Forest, Autoencoders, clustering).

        - Deploy a real-time fraud flagger API with dashboards for suspicious activity.

    - **Impact**: Recruiters love fraud detection → it screams machine learning applied to money.
